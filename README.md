# Famished

空腹や低HPになると、プレイヤーが弱くなる Minecraft の Mod です。

> このmodは大部分または全てAIによって作成されました。

## 効果

### 空腹時のリーチ・攻撃力低下

プレイヤーの満腹度に応じて、エンティティへの攻撃リーチ（`forge:entity_reach`）と攻撃力（`generic.attack_damage`）が下がります。

| 満腹度 | リーチ | 攻撃力 |
| --- | --- | --- |
| 7以上 | 変化なし | 変化なし |
| 3〜6 | -0.5 | -4 |
| 0〜2 | -1.0 | -4 |

攻撃力の低下量は、弱体化 I の効果と同じです。

### 低HP時の移動速度低下

プレイヤーのHPに応じて、移動速度（`generic.movement_speed`）が下がります。

| HP | 移動速度 |
| --- | --- |
| 11以上（ハート5.5個以上） | 変化なし |
| 7〜10 | -10% |
| 5〜6 | -25% |
| 4以下（ハート2個以下） | -40% |

クリエイティブモードとスペクテイターモードでは、どの効果も受けません。

## 対応環境

- Minecraft 1.20.1
- Forge 47.3.0 以降

## 導入方法

1. [Releases](../../releases) から `famished-1.1.0.jar` をダウンロードします。
2. ダウンロードした jar を、Minecraft の `mods` フォルダに入れます。
3. Forge 1.20.1 でゲームを起動します。

## ビルド方法

Java 17 と Gradle が必要です。

```
gradle build
```

`build/libs` に jar が作られます。
